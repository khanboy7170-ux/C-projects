---

## 📌 Key Implementations

### 1. Data Structures
* **Linear Structures:** Singly Linked List, Doubly Linked List, Stack (Array & Pointer based), Queue, Circular Queue.
* **Non-Linear Structures:** Binary Trees, Binary Search Tree (BST), Tree Traversals (Inorder, Preorder, Postorder).

### 2. Algorithms
* **Searching:** Linear Search, Binary Search.
* **Sorting:** Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, Merge Sort.

### 3. Core Systems & Memory Concepts
* **Pointer Arithmetic:** Double pointers, function pointers, pointer casting.
* **Dynamic Memory Management:** Allocation and deallocation using `malloc()`, `calloc()`, `realloc()`, and `free()`.
* **File Operations & Structures:** File handling (`fopen`, `fread`, `fwrite`), user-defined types via `struct` and `union`.
